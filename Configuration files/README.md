# Configuration files
This folder contains mostly Klipper configuration files.

## Guide
* fn_key.cfg
    * A configuration file made specifically to replace *kill_switch* inside *[display]* section. If the key in-question has wired directly to the reset key of MCU then this will be useless.
    * Default functions are provided.
* exs.cfg
    * A dedicated configuration file made for Exhaust XS.

## Other notes
* Only followers of Oitswilliam Pang from Facebook, Instagram and subscribers on YouTube can view and borrow Oitswilliam's printers' (V0.2378) current configurations. This folder holds cleaned-up configurations.
